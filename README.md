# 🔄 SkillSwap — Peer-to-Peer Skill Exchange Network

SkillSwap is a student-focused peer learning platform that enables college students to exchange skills, share knowledge, and learn from one another without paying money.

Students can offer skills they already know and discover peers who can teach the skills they want to acquire. The platform uses reciprocal skill matching to connect students with compatible learning goals.

## 🚀 Features

- **Skill Discovery:** Explore skills offered by students across different categories.
- **Reciprocal Skill Matching:** Identify students who can teach each other the skills they want to learn.
- **Compatibility Score:** Calculate match compatibility based on skill alignment, availability, and learning preferences.
- **Skill Categories:** Browse Programming, Web Development, AI/ML, Design, Mathematics, Communication, and more.
- **Search & Filters:** Find students by name, skill, department, experience, and availability.
- **Skill Exchange Requests:** Send, accept, reject, and track peer learning requests.
- **Skill Credit Wallet:** Earn simulated credits by completing skill exchange sessions.
- **Exchange Management:** Track pending, accepted, active, and completed exchanges.
- **Student Profiles:** Manage skills offered, skills wanted, learning preferences, and profile information.
- **Community Feed:** Explore trending skills, learning activity, and student achievements.
- **Notifications:** Receive in-app updates about exchange requests and completed sessions.
- **Responsive UI:** Optimized for desktop, tablet, and mobile.
- **Local Storage Persistence:** Preserve application data across browser refreshes.

## 🎯 Problem Statement

College students often possess valuable skills but lack an organized platform to exchange knowledge with their peers.

Traditional learning platforms usually focus on paid courses or one-way mentorship, making collaborative learning less accessible.

SkillSwap addresses this challenge by creating a peer-to-peer skill exchange ecosystem where students can learn from each other through mutually beneficial exchanges.

## 💡 Solution

SkillSwap encourages collaborative learning through a reciprocal exchange model.

1. Students create profiles listing skills they can teach.
2. Students specify skills they want to learn.
3. The platform identifies compatible peer matches.
4. Students send skill exchange requests.
5. Sessions are completed through online, in-person, or hybrid learning.
6. Students earn simulated Skill Credits for teaching and completing exchanges.

## 🌟 Unique Features

### Reciprocal Skill Matching

The platform identifies mutually beneficial learning partnerships.

Example:

- Student A can teach C++ and wants to learn UI/UX Design.
- Student B can teach UI/UX Design and wants to learn C++.

SkillSwap identifies the students as a compatible match.

### Skill Credit Wallet

Students earn simulated Skill Credits for teaching sessions.

Credits are used to encourage participation and recognize peer contributions. The credit system is for demonstration purposes and does not represent real money.
